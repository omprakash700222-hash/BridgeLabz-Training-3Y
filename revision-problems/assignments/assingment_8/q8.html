CSS Box-Sizing Comparison

content-box

Width: 300px
Padding: 30px
Border: 10px

Total Rendered Width = 380px

border-box

Width: 300px
Padding: 30px
Border: 10px

Total Rendered Width = 300px

Explanation: content-box adds padding and borders on top of the specified width, making the box larger. border-box includes padding and border within the specified width.
